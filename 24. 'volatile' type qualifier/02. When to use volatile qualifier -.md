# When to Use `volatile` in C?

## 1. When to Use `volatile` ?

- Declare a variable `volatile` when its value can **change unexpectedly**.
- The unexpected change can come from:
  1. Within the code
  2. Outside the code(Hardware)

- **Pin read example:** the `pin status` variable can change at any time because the user may change the state of pin PA0. This is an unexpected change, so `volatile` is needed.

### The Three Main Scenarios for where to use 'Volatile' qualifier?

1. **Memory-mapped peripheral registers** of the microcontroller.(PIN read example)

2. **Global variables shared between multiple tasks** in an RTOS / multi-threaded application.

3. **Global variables shared between main code and an ISR**.

- Use `volatile` generously in these cases.
- In other cases `volatile` is **not required**.
- The pin read example falls under case 1, because it accesses a memory-mapped peripheral register. It is fixed in the exercise below.

## 2. Syntax Cases

### Case 1: Volatile data

```c
uint8_t volatile my_data;   // preferred
volatile uint8_t my_data;   // identical, also fine
```

- Read as: `my_data` is a **volatile variable of type `uint8_t`**.

### Case 2: Non-volatile pointer to volatile data

```c
uint8_t volatile *pStatusReg;
```

- Read as: `pStatusReg` is a **non-volatile pointer** pointing to **volatile data** of type `uint8_t`.
- This is the **most frequently used** form in embedded programming, and the one for accessing **memory-mapped registers**.
- It is similar to how `const` works: one part applies to the data, the other to the pointer.
- It tells the compiler that the data pointed to may change unexpectedly, so **no optimization** is applied to reads and writes through this pointer.

### Cases 3 and 4 (rarely used)

### **Case 3:** volatile pointer to non-volatile data.
```c
uint8_t *volatile pStatusReg;
```

- pStatusReg is a volatile pointer, pointing to a non-volatile data of type unsigned integer uint8_t.

### **Case 4:** volatile pointer to volatile data.
```c
uint8_t volatile *volatile pStatusReg;
```

- pStatusReg is a volatile pointer, pointing to volatile data of type unsigned integer `uint8_t`.


## 3. Extra Notes

- `const` and `volatile` can be applied to **any declaration**, including:
  - structures
  - unions
  - enumerated types
  - typedef names
